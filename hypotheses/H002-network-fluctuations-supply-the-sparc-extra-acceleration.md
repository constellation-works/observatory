# H002 — Network fluctuations supply the SPARC extra acceleration

Origin: [`_archive/lineage/nodes/network-force.md`](../_archive/lineage/nodes/network-force.md).

## The claim

The acceleration beyond what visible baryons produce is generated by a dynamic,
connection-forming network between galaxies, whose galaxy-to-galaxy fluctuation
is large enough to be a mechanism rather than a fitted constant.

## What would refute it

The node's kill condition: the forward model bounds `sigma_net` below what any
network mechanism predicts. [`R003`](../research/R003-network-force/) set that
bound at 0.171 dex; whether it is below what a network predicts needs a network
that predicts a number, which no version of this claim yet does.
