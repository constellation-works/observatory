# Q002 — Is proper time a count of snapshots along a worldline

Origin: Daniel's seed, 2026-09-20, from a conversation refining an intuition
about motion, space and time. Captured here as a question because it is not yet
a claim a run could come out against.

## The intuition

Reality advances as a sequence of discrete snapshots. A stationary object
collects many snapshots per unit distance; a moving one collects fewer; at the
speed of light the last snapshot never gets a successor and the object is stuck
in one persistent frame. A sand clock carried along the path pours one grain per
snapshot, so a fast mover's sand falls slowly and a stopped one's falls fast.
Time flow is snapshot density along the path.

## Where the conversation landed

- The sand clock is proper time. Snapshots per unit reference time go as
  √(1 − v²/c²); the total between two events is the integral along the path.
- Snapshots must belong to worldlines, not to a global "reality". A universal
  cadence is a preferred frame, and mutual time dilation between passing
  observers only works if each path has its own count.
- Velocity sets the count, not acceleration (clock hypothesis; muon storage
  rings).
- The light-speed limit is zero elapsed snapshots, better phrased as "emission
  and absorption fall in the same frame". A massless thing has no viewpoint, so
  "what the photon sees" is a count, not a camera.
- The picture bundles two different notions of snapshot. Frames *along a path*
  (invariant; time dilation) and a frame *as a picture of the whole world at one
  moment* (observer-dependent; length contraction). A moment that is
  instantaneous in one frame is a rolling-shutter scan in every other, which is
  relativity of simultaneity. What a camera actually records is Terrell-Penrose
  rotation, not contraction.
- Gravity fits for free: snapshot density is lower deep in a potential well.
- Closest existing formalism is causal set theory (Sorkin, Bombelli et al.):
  proper time along a worldline is the number of elements on the longest chain;
  a "moment" is any antichain; random sprinkling gives Lorentz invariance with no
  cadence anywhere. The difference in direction: the snapshot picture starts from
  sequence and derives causality; causal sets start from causal order and derive
  the count. Sequence implies a frame, order does not.
- What the intuition cannot yet do: explain why the speed of light is
  frame-independent, which is the postulate the rest follows from. Spatial
  distance from pure order is an open problem in causal set theory as well.

## The question

Is the snapshot picture exactly the causal-set account seen from inside a single
worldline, or does it carry any content causal sets do not? Concretely: is there
a way to state "snapshot count along a path" that reproduces proper time without
smuggling in a preferred frame, and does the "persistent frame at c" reading add
anything to the null-interval statement?

## What would answer it

A short derivation showing that a Poisson-sprinkled discrete spacetime with
snapshot count defined as longest-chain length gives (a) the √(1 − v²/c²) rate,
(b) mutual dilation between passing observers with no preferred frame, and
(c) length contraction as a change of antichain. If all three fall out, the
picture is causal sets and the productive next step is a hypothesis about what a
"frame-independent limit on frames per distance" means in that setting. If any
fails, the failure is the new content.
