# notebooks

Free-form human exploration. Nothing here carries a frontmatter contract and the
check gate skips it.

Outputs are stripped on commit (`nbstripout`, installed by `make setup`). A
notebook that produces a result worth keeping is promoted into a research item:
the code moves to `R###-slug/code/`, the numbers into its README.

`astrolabe/` holds the notebooks that came with the astrolabe library
(`_lib/astrolabe`).
