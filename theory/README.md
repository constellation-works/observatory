# theory/

Our own theories — one directory per line of inquiry. Almanac keeps the *discussion*
(how an idea unfolded); this directory keeps the *current state of the theory* and its
standing against evidence. The canonical claim list is `theory/<slug>/claims.json`. The
`evidence-ledger.md` table must match it. A cross-family rollup lives in
[../ledger.md](../ledger.md), generated by `python3 scripts/check-theory.py --write-ledger`.
The procedure is [../policy.md](../policy.md).

Each theory is `theory/<slug>/`:

```
theory/<slug>/
  README.md              # hub: frontmatter, idea, current verdict, Contents
  claims.json            # canonical registry; "doc" == <slug>
  evidence-ledger.md     # ## Evidence ledger — the only H2
  related.md             # ## Related — the only H2
  open-questions.md      # ## Open questions — the only H2
  <chapter>.md           # optional argument chapters
```

Open `theory/<slug>/README.md` for the live verdict — never the directory listing.
Generated `ledger.md` links `theory/<slug>/` (GitHub renders the hub).

## The contract

Each hub carries frontmatter (`title`, `status`, `families`, `almanac`, `created`, `updated`)
that must match `claims.json` on `title`, `status`, and `families`. The registry is
canonical for id, family, kind, status, kill, and control. The **evidence ledger** table
maps each claim to its status and the sims/studies that back it. Kinds are `postulate`,
`derived`, `model-property`, `nature`, and `hook` — see [../policy.md](../policy.md).
Claim statuses:

| Claim status | Meaning |
|---|---|
| `supported` | a sim or study backs it, linked in the row |
| `mixed` | evidence cuts both ways — the row says how |
| `untested` | stated but not yet simulated/sourced |
| `refuted` | evidence kills it — the row links what did |
| `conjecture` | not yet backed by anything; flagged pending a study note |

Doc-level `status`: `exploratory` (being built), `growing` (active work), `refuted`
(the central claim is dead — doc stays, see below), `resolved` (converged with established
physics; kept as a correspondence record), and `retired` (research discontinued by
Daniel; individual claim verdicts preserved).

## Rules of the house

- **Theory bends to evidence.** A sim or study that contradicts a claim changes the claim's
  status in the same commit that lands the evidence.
- **Refuted branches stay.** A dead line of inquiry keeps its doc, its status, and its
  refuting evidence. It is a result.
- **Cite or label conjecture.** Established-physics facts lean on a `../../studies/` note
  with a real citation, or are marked `conjecture — to verify`.
- **Update a claim in both files.** `claims.json` and `evidence-ledger.md` change in the
  same commit. Add or close an open question in `open-questions.md`. Sibling and study
  pointers live in `related.md`.
