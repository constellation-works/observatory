# theory

Claims that survived, and the lock that keeps them honest. This is principia,
folded in with its history: `policy.md`, `theory/<doc>/claims.json` registries,
`gates/`, `schema/wall.json` (the refuted wall), and the checker at
`_scripts/check-theory.py`.

Read `policy.md` before changing anything here. Nebula graduates a node into
this layer with `neb graduate <id> --to knowledgebase/theory/<doc>`, and only a
node with a kill condition can graduate.
