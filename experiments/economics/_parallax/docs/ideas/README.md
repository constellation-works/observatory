# Parallax idea inbox

Capture undeveloped thoughts as `I<NNN>-<lowercase-kebab-title>.md`, beginning with `I001`. Idea
numbers are repository-wide permanent identities: use the next unused number, and never reuse or
renumber one.

Ideas are deliberately less formal than hypotheses. They need no preregistered method or rejection
criterion. When an idea matures, create the appropriate numbered research program, hypothesis,
experiment, supporting document, or external venture and link it from the idea's graduation history.
Keep the original idea as provenance, including ideas that go nowhere.
