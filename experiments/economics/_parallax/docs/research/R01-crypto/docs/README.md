# R01 crypto supporting documents

Use this directory for domain knowledge, literature notes, data-source assessments, derivations,
and design notes that inform R01 without being a hypothesis or experiment record. Use descriptive
lowercase kebab-case filenames. Supporting documents may change as understanding improves; frozen
hypotheses and completed experiment records may not be rewritten to match them.

The established program-level contracts remain at the R01 root and are indexed by the
[`R01 charter`](../README.md).
