# Parallax session handoffs

Write a handoff only when Daniel requests a session summary. Name it
`<YYYY-MM-DD>-<lowercase-kebab-title>.md`; when more than one handoff on a date would use the same
title, choose a more specific title rather than overwriting the earlier record.

A handoff preserves the objective, starting context, decisions, completed work, evidence, open
threads, and the exact place to resume. It points to durable idea, hypothesis, experiment, research,
code, and artifact records instead of duplicating them. It is a concise continuation aid, not a raw
chat transcript, activity log, or substitute for an experiment record.
