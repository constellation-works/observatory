# FPUT recurrence reproduction protocol v1

Status: **frozen** on 2026-09-12. This is an independent reconstruction of
Fig. 1 in E. Fermi, J. Pasta, S. Ulam (with M. Tsingou), *Studies of
Nonlinear Problems, I*, LA-1940 (1955), report p. 12 / PDF p. 14. The public
source and its digest are in
[`data/manifest.json`](../../data/manifest.json).

The machine-readable file loaded by the future runner is
[`v1.json`](v1.json). This milestone freezes records, contracts and reference
extraction only: it does not implement the integrator or runner.

## Target and expected output

Reproduce the report's first five mode energies for `N=32`, `alpha=1/4`, and
caption value `delta t^2=1/8`, over 30,000 computational cycles. Emit five
mode-energy time series for modes 1–5, sampled at least every 50 cycles (601
samples including cycle zero). One computational cycle is one integration time
step. The report's abscissa is cycles times `delta t`; the caption's
`delta t^2` is the acceleration coefficient, so the baseline time step is
`delta t = 1/sqrt(8) = 0.3535533905932738`, never `1/8`.

The comparison axis uses
`E_k(t) / E_1(0) * 300`, so the initial mode-1 value is 300 report units.
The CSV reference is digitized from the figure and is not the original
MANIAC dataset.

## Model, units and initial state

Use the quadratic FPUT chain with unit masses and fixed ends:

```text
ddot{x}_i = (x_{i+1} + x_{i-1} - 2 x_i)
            + alpha [(x_{i+1} - x_i)^2 - (x_i - x_{i-1})^2]
```

Here `i=1,...,N-1`, `x_0=x_N=0`, `N=32`, `alpha=0.25`, `beta=0`, and all
quantities are dimensionless except for the cycle label. The string starts
from rest with one normalized sine wave:

```text
x_i(0) = sin(i*pi/N),   v_i(0) = 0.
```

Mode analysis follows the report:

```text
a_k     = sum_i x_i sin(i*pi*k/N)
omega_k = 2 sin(pi*k/(2*N))
E_k     = 1/2 (adot_k^2 + omega_k^2 a_k^2)
adot_k  = sum_i v_i sin(i*pi*k/N)
```

The plotted modal energy omits the nonlinear potential contribution, which the
report says is at most a few percent. Control C2 separately audits the full
quadratic-plus-cubic chain energy.

## Integrator and solver settings

The baseline is an explicit central-difference / Störmer–Verlet update in the
`x` variables. This is an assumption: no author code exists, and the report's
description of replacing derivatives with difference expressions is being
reconstructed as the following velocity-Verlet form.

1. Evaluate `a(x^0)` with fixed end points.
2. Apply the startup **first half-kick**
   `v^(1/2) = v^0 + (delta t / 2) a(x^0)`; `v^0=0`.
3. Drift `x^1 = x^0 + delta t v^(1/2)`, evaluate `a(x^1)`, and complete the
   first step with `v^1 = v^(1/2) + (delta t / 2) a(x^1)`.
4. For every later step, half-kick, drift, recompute acceleration, and
   complete the kick in the same order. Equivalently after startup,
   `x^(n+1)=2x^n-x^(n-1)+(delta t)^2 a(x^n)`.

Use IEEE-754 `float64`, no random seed, no adaptive stepping, and no iterative
solver tolerance. Run exactly 30,000 baseline steps and sample at cycles
`0,50,...,30000`. Non-finite state is a failed run. Fixed end points are
reapplied at every force evaluation.

## Inputs and compute envelope

Use `reference/fig1-digitized.csv` only for named comparison features. Read
the CSV header and rows, retain the feature labels and stated uncertainties,
and never fit `alpha`, `delta t`, or any other baseline parameter to the
curves. The source PDF is fetched to a temporary path and is not tracked.

A throwaway float64 throughput probe on `dk-server-1 / ws_observatory` took
0.34 seconds on 2026-09-12 for the 32-site force/update shape. The future
runner must measure its own runtime in the log and `run.json`; plan for a
bounded timeout of **at most 120 seconds**, with expected runtime under one
second and memory under 256 MiB on this host. Record Python/package versions,
`uv.lock` digest, git revision, input hashes, wall-clock start/end and status.

## Metrics

| id | observable | reference and pass tolerance |
|---|---|---|
| M1 (primary) | First mode-1 recurrence, `argmax E_1` over cycles 20,000–30,000 | Absolute difference from the digitized recurrence time ≤ 1,000 cycles. |
| M2 | `E_1(t_rec)/E_1(0)` | Within ±0.03 of the digitized recurrence fraction. |
| M3 | Time and height of first maxima of modes 2, 3 and 4 | Time within ±5% of each digitized time; height within ±10% of `E_1(0)` on the normalized report axis. |
| M4 | Maximum summed energy of modes 6–31 over the run | ≤ `20/300 = 0.0666666667` of `E_1(0)`, matching the caption's “higher modes never exceeded 20” statement. |

## Controls

- **C1 — report control:** set `alpha=0`; `E_1` stays within 1% of its
  initial value for 10,000 cycles.
- **C2 — full energy:** include the cubic nonlinear spring potential and keep
  total energy's maximum relative drift within 1% over 30,000 baseline cycles.
- **C3 — convergence:** halve `delta t`, hold physical elapsed time fixed,
  and move the physical recurrence time by less than 1%.

Any failed control yields execution status **failed control**, with metrics and
diagnostics retained. If M1 misses its tolerance, report **discrepancy** and
do not tune it away. Use **inconclusive** when required evidence cannot be
evaluated or the stated digitization uncertainty prevents a decision.

## Amendment rule

After this task lands, `protocol/v1.md` and `protocol/v1.json` are immutable.
Any method or parameter change creates `protocol/v2.md` and `protocol/v2.json`
with a dated reason and leaves v1 untouched. Exploratory readings, including
the alternative `delta t=1/8`, belong only to explicitly labelled exploratory
runs and can never overwrite the registered baseline.
