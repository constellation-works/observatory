# FPUT recurrence reproduction protocol v2

Status: **frozen** on 2026-09-12. Supersedes
[`v1.md`](v1.md) / [`v1.json`](v1.json), which stay frozen and byte-identical
to their original landing and describe the pre-repair reading. This is an
independent reconstruction of Fig. 1 in E. Fermi, J. Pasta, S. Ulam (with M.
Tsingou), *Studies of Nonlinear Problems, I*, LA-1940 (1955), report p. 12 /
PDF p. 14. The public source and its digest are in
[`data/manifest.json`](../../data/manifest.json).

The machine-readable file loaded by the runner is [`v2.json`](v2.json).
Everything in this document is identical to v1 except the four amendments
below; each is dated and, since it responds to something observed only after
running v1's baseline, marked `post_hoc: true` in `v2.json`. No tolerance,
parameter, or integrator value changes anywhere in this document.

## Target and expected output

Reproduce the report's first five mode energies for `N=32`, `alpha=1/4`, and
caption value `delta t^2=1/8`, over 30,000 computational cycles. Emit five
mode-energy time series for modes 1–5, sampled at least every 50 cycles (601
samples including cycle zero). One computational cycle is one integration time
step. The report's abscissa is cycles times `delta t`; the caption's
`delta t^2` is the acceleration coefficient, so the baseline time step is
`delta t = 1/sqrt(8) = 0.3535533905932738`, never `1/8`.

The comparison axis uses
`E_k(t) / E_1(0) * 300`, so the initial mode-1 value is 300 report units.
The CSV reference is digitized from the figure and is not the original
MANIAC dataset.

## Model, units and initial state

Use the quadratic FPUT chain with unit masses and fixed ends:

```text
ddot{x}_i = (x_{i+1} + x_{i-1} - 2 x_i)
            + alpha [(x_{i+1} - x_i)^2 - (x_i - x_{i-1})^2]
```

Here `i=1,...,N-1`, `x_0=x_N=0`, `N=32`, `alpha=0.25`, `beta=0`, and all
quantities are dimensionless except for the cycle label. The string starts
from rest with one normalized sine wave:

```text
x_i(0) = sin(i*pi/N),   v_i(0) = 0.
```

Mode analysis follows the report:

```text
a_k     = sum_i x_i sin(i*pi*k/N)
omega_k = 2 sin(pi*k/(2*N))
E_k     = 1/2 (adot_k^2 + omega_k^2 a_k^2)
adot_k  = sum_i v_i sin(i*pi*k/N)
```

The plotted modal energy omits the nonlinear potential contribution, which the
report says is at most a few percent. Control C2 separately audits the full
quadratic-plus-cubic chain energy.

## Integrator and solver settings

The baseline is an explicit central-difference / Störmer–Verlet update in the
`x` variables. This is an assumption: no author code exists, and the report's
description of replacing derivatives with difference expressions is being
reconstructed as the following velocity-Verlet form.

1. Evaluate `a(x^0)` with fixed end points.
2. Apply the startup **first half-kick**
   `v^(1/2) = v^0 + (delta t / 2) a(x^0)`; `v^0=0`.
3. Drift `x^1 = x^0 + delta t v^(1/2)`, evaluate `a(x^1)`, and complete the
   first step with `v^1 = v^(1/2) + (delta t / 2) a(x^1)`.
4. For every later step, half-kick, drift, recompute acceleration, and
   complete the kick in the same order. Equivalently after startup,
   `x^(n+1)=2x^n-x^(n-1)+(delta t)^2 a(x^n)`.

Use IEEE-754 `float64`, no random seed, no adaptive stepping, and no iterative
solver tolerance. Run exactly 30,000 baseline steps and sample at cycles
`0,50,...,30000`. Non-finite state is a failed run. Fixed end points are
reapplied at every force evaluation.

## Inputs and compute envelope

Use `reference/fig1-digitized.csv` only for named comparison features. Read
the CSV header and rows, retain the feature labels and stated uncertainties,
and never fit `alpha`, `delta t`, or any other baseline parameter to the
curves. The source PDF is fetched to a temporary path and is not tracked.

## Metrics

| id | observable | reference and pass tolerance |
|---|---|---|
| M1 (primary) | First mode-1 recurrence, `argmax E_1` over cycles 20,000–30,000 | Absolute difference from the digitized recurrence time ≤ 1,000 cycles. |
| M2 | `E_1(t_rec)/E_1(0)` | Within ±0.03 of the digitized recurrence fraction. |
| M3 | Global maximum of modes 2, 3, and 4 over cycles 0–20,000 | Time within ±5% of each digitized time; height within ±10% of `E_1(0)` on the normalized report axis. Also reports (does not gate) mode 5's first major peak and mode 3's second maximum (~19k cycles), each with its residual. |
| M4 | Maximum single-mode energy over modes 6–31 and over the run | ≤ `20/300 = 0.0666666667` of `E_1(0)`, matching the caption's “higher modes never exceeded in energy 20” statement, read per mode. Also reports the summed modes-6–31 value for transparency. |

**Amendment 2, M3 (post hoc):** v1 defined M3 as the *first local maximum*,
which caught sub-1% early bumps (v1 measured mode 2's first local maximum at
t=200 cycles, 0.7 units) instead of the labelled major peak the figure and
report text describe. v2 redefines M3 as the *global maximum of modes 2, 3,
and 4 over cycles 0–20,000* — the labelled major peaks — while keeping the
±5%/±10% tolerances unchanged. This was found by running v1's baseline on
2026-09-12, after the fact.

**Amendment 3, M4 (post hoc):** the caption states "the higher modes never
exceeded in energy 20 of our units," describing an individual-mode ceiling.
v1 summed modes 6–31 (measured 25.4 units for the sum), misreading the
caption. v2 redefines M4 as the *maximum single-mode energy* over modes 6–31
and the whole run, keeping the 20/300 threshold unchanged, and still reports
the summed value for transparency. Found by running v1's baseline on
2026-09-12.

## Controls

- **C1 — report control:** set `alpha=0`; `E_1` stays within 1% of its
  initial value for 10,000 cycles. Gating.
- **C2 — full energy:** include the cubic nonlinear spring potential and keep
  total energy's maximum relative drift within 1% over 30,000 baseline cycles.
  Gating.
- **C3 — convergence:** halve `delta t`, hold physical elapsed time fixed,
  and move the physical recurrence time by less than 1%. Reported, not
  gating (see Amendment 4).

**Amendment 4, C3 (post hoc):** v1 measured a 5.1% shift of `t_rec` when
halving `delta t`, above the unchanged 1% threshold, and this failure flipped
v1's execution status to "failed control." The reproduction target is the
MANIAC computation *at its own step* (`delta t^2 = 1/8`); continuum
convergence is not a precondition for reproducing the paper's figure, but the
sensitivity is a real, scientifically meaningful finding that must stay
visible. v2 keeps C3's definition and 1% threshold unchanged but reclassifies
it as a reported sensitivity check: execution status now depends only on the
gating controls C1 and C2 (plus the primary metrics M1/M2), and C3's own
pass/fail is retained and quoted in the study note regardless. Found by
running v1's baseline on 2026-09-12.

Any failed *gating* control (C1 or C2) yields execution status **failed
control**, with metrics and diagnostics retained. If M1 misses its tolerance,
report **discrepancy** and do not tune it away. Use **inconclusive** when
required evidence cannot be evaluated or the stated digitization uncertainty
prevents a decision.
