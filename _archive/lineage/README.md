# lineage

The personal nebula corpus. `make setup` exports `NEBULA_ROOT` here, so
`neb capture`, `neb trace` and `neb check` all operate on it.

`config.yaml` declares the domains; `nodes/` holds one file per idea; `inbox/`
holds raw captures by month. Nothing is ever deleted: refuted and abandoned
nodes are kept because they are what stops re-treading ground.

The work corpus is a separate corpus outside this repository.
